# 만능 영상 도구: 무료 웹 테스트 버전

공개 링크로 영상 정보를 확인하고, 720p 원본 또는 음성 제거 파일과 광고 없는 1080p 테스트 파일을 브라우저에서 받는 Streamlit 앱입니다.

## 무료 공개 테스트 배포

1. 이 폴더의 파일을 새 GitHub 저장소에 올립니다.
2. https://share.streamlit.io 에서 GitHub 계정으로 로그인합니다.
3. 저장소와 `app.py`를 선택해 배포합니다.
4. 앱 설정의 Secrets에 아래처럼 강한 관리자 비밀번호를 등록합니다.

```toml
ADMIN_PASSWORD = "긴 임의 비밀번호"
```

배포 후 `https://원하는이름.streamlit.app` 형태의 주소를 사용할 수 있습니다. 직접 게시하려면 GitHub 계정 로그인이 필요합니다. 이 패키지는 아직 인터넷에 게시되지 않았습니다.

## 포함된 기능

- 지원되는 공개 영상 URL의 메타정보와 썸네일 표시\n- Vimeo는 공개 미리보기를 oEmbed로 표시하며, 로그인이 필요한 다운로드는 제공하지 않음
- 최대 720p 원본 및 음성 제거 다운로드
- 광고 없이 최대 1080p 원본 다운로드 테스트 옵션 (광고 연동 전이며, 원본이 1080p 미만이면 제공 가능한 최고 화질)
- 파일당 최대 200MB, 영상 길이 최대 15분 제한
- 익명 세션 기준 방문자, 다운로드 요청 수와 요청 파일 용량의 최근 24시간 통계
- 한국어·영어·일본어 화면 및 안내/경고문 선택\n- 관리자 통계 비밀번호 잠금 및 수동 초기화 버튼

## 제한

- 광고 네트워크와 광고 시청 보상 다운로드는 연결되어 있지 않습니다. 관리자 화면에는 광고 시청 수 대신 미연동으로 표시됩니다.
- 통계와 임시 파일은 서버 메모리에서만 처리합니다. 무료 서버가 재시작되거나 앱이 잠들면 통계가 초기화될 수 있습니다.
- 다운로드 요청 용량은 브라우저에 파일을 제공하려 한 양이며, 사용자가 끝까지 저장했는지를 확인한 값은 아닙니다.
- Streamlit Community Cloud는 무료 테스트용입니다. 동시 사용자/대용량 다운로드가 늘면 속도나 가용성이 제한될 수 있습니다.
- yt-dlp가 지원하는 모든 사이트가 항상 동작하는 것은 아닙니다. 사이트의 접근 제한·변경에 따라 실패할 수 있습니다.
- 공개 사이트에만 사용하도록 URL을 제한했지만, 임의 URL을 서버가 가져오는 구조에는 운영·악용 위험이 남아 있습니다. 안정적인 공개 서비스로 운영하려면 별도 다운로드 작업 큐, 요청 제한, abuse 대응과 서버 자원 정책을 추가해야 합니다.
- 서비스 이용자는 다운로드 권리와 각 사이트의 이용 약관을 확인해야 합니다.

## 로컬 실행

Python과 FFmpeg 설치 후:

```bash
pip install -r requirements.txt
streamlit run app.py
```

관리자 통계를 로컬에서 열려면 `.streamlit/secrets.toml`에 위의 `ADMIN_PASSWORD`를 입력합니다. 이 파일을 GitHub에 올리지 마세요.
